# Сканер склада — приложение для терминала UROVO DT40

Простое приложение для терминала сбора данных (ТСД) **UROVO DT40**:
загрузка баз товаров по магазинам, быстрый подсчёт при сканировании и
сверка «план/факт» с поиском расхождений. Интерфейс на **русском и китайском**
языках (переключается прямо в приложении).

---

## Что умеет приложение

Функции разделены на четыре понятных раздела в главном меню:

1. **Магазины (базы товаров)** — загрузка базы из файла `.xlsx` (такой же
   выгрузки, как у вас сейчас), присвоение ей названия магазина и выбор
   «активной» базы. Баз может быть много — по одной на каждый магазин.
2. **Сканирование и подсчёт** — сканируете товары один за другим, приложение
   считает количество каждого штрихкода и показывает название из активной базы.
   Итоги (сколько позиций и сколько всего единиц) видны сверху. Можно
   экспортировать результат в CSV (открывается в Excel).
3. **Сверка и расхождения** — загружаете плановое количество (из файла `.xlsx`
   или из ранее сохранённого подсчёта) и сравниваете с фактически
   отсканированным. Приложение показывает недостачи, излишки, не отсканированные
   и лишние позиции, и умеет выгрузить отчёт.
4. **Настройки** — язык, режим работы сканера, звук и вибрация.

## Как получить APK (файл приложения)

Готовый `.apk` не входит в комплект, потому что его нужно **собрать**. Ниже —
два способа. **Способ 1 не требует установки программ** и рекомендуется.

### Способ 1 (рекомендуемый): автоматическая сборка на GitHub

1. Зарегистрируйтесь на [github.com](https://github.com) (бесплатно) и войдите.
2. Нажмите **New repository** (создать репозиторий). Дайте любое имя, например
   `warehouse-scanner`, выберите **Public** или **Private** и нажмите
   **Create repository**.
3. На странице пустого репозитория нажмите ссылку **uploading an existing file**
   (загрузить существующие файлы). Перетащите в окно **всё содержимое** этой
   папки (включая скрытую папку `.github` — она отвечает за сборку). Проще
   всего: заархивировать всё в один zip **не нужно** — загружайте файлы и папки
   как есть. Нажмите **Commit changes**.
4. Откройте вкладку **Actions** вверху репозитория. Через несколько секунд
   появится задача **Build APK**. Дождитесь **зелёной галочки** (сборка идёт
   примерно 2–4 минуты).
5. Кликните на завершённую задачу, прокрутите вниз до раздела **Artifacts** и
   скачайте архив **warehouse-scanner-apk**. Внутри — файл `app-debug.apk`.

> Если сборка не запустилась сама, откройте вкладку **Actions**, слева выберите
> **Build APK** и нажмите **Run workflow**.

### Способ 2: сборка в Android Studio (на компьютере)

1. Установите [Android Studio](https://developer.android.com/studio).
2. **File → Open** и выберите эту папку. Дождитесь, пока Gradle загрузит
   зависимости (нужен интернет).
3. Меню **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Готовый файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Установка APK на терминал UROVO DT40

1. Скопируйте `app-debug.apk` на терминал (через USB-кабель или отправьте себе
   любым удобным способом).
2. На терминале откройте файл. Если система попросит — разрешите **установку из
   неизвестных источников** для файлового менеджера/браузера.
3. Установите и запустите «Сканер склада».

## Настройка сканера (важно)

У приложения два режима приёма штрихкодов (раздел **Настройки → Режим сканера**):

- **Клавиатурный (по умолчанию).** Подходит для большинства терминалов сразу.
  Встроенный сканер должен работать в режиме «клавиатуры» и отправлять **Enter**
  после штрихкода. На UROVO это настраивается в системном приложении
  **ScanSetting** (или **Scanner**): режим вывода — *Keyboard / Focus mode*,
  суффикс — *Enter (\r\n)*.
- **Broadcast (Intent).** Если хотите более надёжный приём без поля ввода:
  в приложении **ScanSetting** терминала включите вывод через *Broadcast /
  Intent output*, а затем в **Настройках** этого приложения впишите те же
  `Action` и имя `extra`, что заданы в ScanSetting. По умолчанию уже вписаны
  типичные для UROVO значения (`android.intent.ACTION_DECODE_DATA` и
  `barcode_string`).

Если после сканирования ничего не происходит в клавиатурном режиме — переключите
режим на Broadcast (или наоборот), это решает проблему на разных прошивках.

## Формат базы товаров

Приложение читает `.xlsx` напрямую (как ваша выгрузка Ozon). При импорте оно
само находит **строку заголовков** и колонки **«Штрихкод»** и **«Название
товара»** — но вы можете поправить выбор вручную перед сохранением. Служебные
строки в начале файла пропускаются автоматически.

Для сверки нужен файл, где есть колонка со **штрихкодом** и колонка с
**количеством** — их вы тоже выбираете при загрузке.

## Частые вопросы

- **Названия товаров не показываются при сканировании.** Не выбрана активная
  база. Зайдите в «Магазины» и нажмите «Сделать активной» у нужной базы.
- **«Нет в базе» при сканировании.** Штрихкод не найден в активной базе — товар
  всё равно посчитается, просто без названия.
- **Куда сохраняются CSV-файлы.** В папку приложения `exports/`; сразу после
  экспорта открывается меню «Поделиться», чтобы отправить файл себе.
